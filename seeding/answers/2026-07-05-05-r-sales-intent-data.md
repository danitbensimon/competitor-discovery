# Thread: Is "intent data" for leads still working for you?
https://www.reddit.com/r/sales/comments/1reb55s/
Tone: reddit casual | Link: NO

---

most 3rd-party intent data fails because you can't verify it. "surging on bombora" is a black box — no way to check why an account got flagged, so reps stop trusting the list and stop working it.

the signals that keep working are the boring public ones you can verify yourself:

- job postings (hiring for a tool = they use it; hiring 5 SDRs = budget exists)
- case studies on a competitor's site = confirmed user of that tool
- g2 reviews, especially negative ones on products you compete with
- new exec hires, funding announcements

the difference is trust: when a rep can see *why* an account is on the list ("posted 3 jobs requiring marketo"), they write sharper emails and actually work it. intent data isn't dead — the unverifiable kind is.
